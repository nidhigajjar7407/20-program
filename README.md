    <li><h2>What's included in this project </h2></li>
    </hr>
      <p>This project includes displaying personal information such as name, age, and city; performing arithmetic operations; displaying messages using console.log(), alert(), and innerHTML; calculating the square and cube of a number; finding the area of a rectangle; demonstrating different data types; using the any data type; converting strings into numbers and numbers into strings; adding string numbers after conversion; swapping two numbers with and without a third variable; calculating student grades, electricity bills, employee salaries, and purchase discounts; checking voting eligibility; converting Celsius into Fahrenheit; and converting minutes into hours and minutes.</p>
    </hr>
      <li><h2>How this project is made</h2></li>
    </hr>
      <p>This project is developed using TypeScript in Visual Studio Code. Variables are declared using the let keyword, and data types such as number, string, boolean, and any are used to store different values. Arithmetic operators are used for calculations, while conditional statements such as if, else if, and else are used to make decisions. Type conversion functions such as Number() and String() are used to convert values from one data type to another. The typeof operator checks the data type of a value, while Math.floor() and the modulus operator help perform mathematical calculations. The console.log() function displays output in the console, while alert() and innerHTML are used to display messages in a browser. TypeScript files are compiled into JavaScript before browser-based programs are executed.</p>
